# AI游戏智播客户端（H5 小游戏 + 自动玩 + AI 弹幕互动）

本地 Electron 客户端，面向 H5 小游戏直播场景：
**游戏库 → 打开 9:16 竖屏游戏 → 录制回放自动玩 / AI 看画面自己玩 → 弹幕抓取 + AI 答疑 + 语音朗读**。

## 运行

```bash
npm install
npm start
```

macOS 上若通过命令行启动且报 Electron 相关错误，用：

```bash
env -u ELECTRON_RUN_AS_NODE ./node_modules/electron/dist/Electron.app/Contents/MacOS/Electron . --no-sandbox
```

> 国内下载 Electron 二进制慢时，用镜像：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node node_modules/electron/install.js`

## 功能总览

左侧 6 个页面：

| 页面 | 作用 |
|---|---|
| 🎮 游戏库 | 管理 H5 小游戏，打开游戏窗口与「自动玩控制台」 |
| 🎙 AI 主播 | 文本朗读、定时播报、背景音乐、声音克隆 |
| 💬 弹幕回复 | 连接抖音直播间抓弹幕，弹幕朗读、AI 读弹幕答疑 |
| 🧩 模型配置 | 所有大模型提供商的统一配置中心 |
| 🎤 声音克隆 | GPT-SoVITS 零样本克隆专属音色 |
| 🔊 声音设备 | 把 AI 语音定向输出到虚拟声卡（进直播间） |

## 一、自动玩（录制 / 回放）

1. 游戏库点卡片「开始」，弹出选择：**继续上次进度** / **重新开始新游戏**，随后并排打开：
   - **游戏窗口**（9:16，414×736）
   - **自动玩控制台**
2. **录制脚本**：
   - 点「● 开始录制」，在游戏里正常操作
   - 「自动标记关卡」默认开启：检测到画面切到新棋盘（变化后重新稳定、且整盘换新）自动分关；
     也可改为「＋ 标记下一关」手动分关
   - 分关原理：不用"画面连续变化就分关"（同一关内的点击/动画会误判），
     而是"画面变化 → 重新稳定 → 稳定画面与之前差异大（整盘换新）才分关"
   - 某关没录好，点「↩ 撤销上一关」可回退重录（可连续撤到任意关）
   - 点「■ 保存并停止」，脚本存到 `scripts/<游戏id>.json`
   - **关卡管理**：列出每关点击数，可「重录」（自动回放前 N-1 关推进后重录）或「删」
3. **自动玩**：点「▶ 开始自动玩」，按录制序列自动点击；每关结束用画面相似度检测切下一关，可循环。

## 二、AI 智能决策（看画面自己玩）

控制台里输入一句自然语言（如「点击键盘上面的数字3一次」），AI 每轮截图 → 判断 → 执行动作。

### 单次 vs 持续任务
含「一次 / 一下 / 单击 / 点这个」等词且不含「一直 / 循环 / 自动过关」→ 判为**单次任务**，
代码层兜底：点完一次强制停止，不依赖模型是否遵守 `done`。

### 模型选择
- 文本模型：启动前做一次策略规划（失败不阻塞）
- 视觉模型：每轮看画面决策
- 选「自动」则按「🧩 模型配置」里的顺序逐级降级重试

### 稳定性设计
- **流式只取答案**：推理模型（如 `hy4-preview`）的思考内容可能长达答案的 60 倍以上，
  会占满 `max_tokens` 导致拿不到 JSON。改用流式请求后，`reasoning_content`（思考）与
  `content`（答案）是两个独立字段，只累加 `content`，思考再长也不影响。兼容不支持流式的服务。
- **停止可立即中断**：模型调用的重试循环内检测停止标志，点停止从"等几十秒"变为立即生效。
- **防死循环**：连续 8 轮未返回有效动作自动停止，状态栏显示 `n/8` 进度。
- **无效动作诊断**：能区分空内容 / 自然语言而非 JSON / JSON 损坏 / `actions` 为空 /
  字段名错 / 被长度截断，并写入日志 `[ai-bad]`，便于判断是"模型看不懂画面"还是"不听话"。
- **坐标精度**：截图按等比缩放到 720 宽（原 414 过小，相邻按钮糊成一片容易点偏）；
  提示词教模型按 10 等分定位小目标；非法坐标（`undefined`/`NaN`）安全跳过。
- **调试日志**：每次点击打印 `[doTap] 模型坐标(0.35,0.78) → 像素(145,574) 窗口414x736`，便于排查点偏。

### 已验证的关键结论（针对 Unity WebGL 游戏）
- 游戏是 **Unity WebGL**，逻辑编译成 WASM，无法直接 hook 内部状态。
- **软点击（注入 JS 派发事件）无效**，游戏不响应。
- **CDP 真实点击有效**（控制台默认），但必须：
  1. 游戏窗口**可见且聚焦**（不能最小化/挪到屏幕外）；
  2. 每次点击先 `mouseMoved` 再 `mousePressed` / `mouseReleased`。
- 游戏**检测桌面端伪装手机 UA** 和**开发者工具窗口**，所以：
  - 用桌面 UA（本客户端默认，不伪装手机）；
  - 不要打开 DevTools，不要调整窗口产生大间隙，否则页面会被判定并清空。
- 进度保存在 **IndexedDB 的 `/idbfs`**（Unity IDBFS 虚拟文件系统）。

## 三、模型配置（统一自定义）

**所有提供商一律是"自定义配置"**，没有内置特殊待遇。每个提供商包含：

`Provider ID` / `显示名称` / `API 地址` / `API Key` / `文本模型` / `视觉模型`

### 自动获取模型
填好地址和 Key 后点「🔄 自动获取模型」，拉取 `/models` 并自动分类：

| 徽章 | 含义 |
|---|---|
| 通用 | 文本和视觉都能用（多模态）。勾选后**同时**写入文本模型和视觉模型 |
| 视觉 | 只能看图 |
| 文本 | 只能处理文字 |
| 免费 / 收费 | 依据接口 `pricing` 字段判定 |
| 已存 | 已配置但接口未返回的模型，保留不清空 |

- 分类兼容 `input_modalities` / `modalities.input` / `architecture.input_modalities` / `capabilities` 多种写法，无则按模型名推测
- 免费判定：`pricing` 全为 0 即免费；无价格信息时按模型名含 `free` 推测（界面会标注"价格按模型名推测"）；
  智谱、硅基流动的 `/models` 不返回价格，显示为未知（不瞎猜）
- 列表**免费优先 → 通用 → 视觉 → 文本**排序，方便挑能白嫖的

### 旧配置迁移
首次加载时会把旧版内置的 4 家（DeepSeek / 智谱 / 硅基流动 / 商汤）已填的 Key 与模型
**自动迁移进自定义配置**，不丢数据；全新安装则预置 4 张空卡片（带默认 API 地址），填 Key 即可用。

## 四、弹幕互动与语音

### 弹幕抓取
连接抖音直播间实时抓取弹幕（需在「显示登录窗口」里扫码登录），可选自动朗读。
内置内容安全过滤：命中联系方式 / 网址 / 广告 / 敏感词等不朗读、不答疑，可用 `aiFilter` 追加自定义黑名单。

### AI 读弹幕答疑
- 「使用模型」下拉直接从「🧩 模型配置」里选，不在本页重复填 Key
- 开关：启用答疑 / 语音回复 / 文字显示
- 「画面识别」开启后用**所选提供商配置的视觉模型**看图回答
- 可调：主播话术、过滤关键词、冷却秒数、失败重试次数
- 「测试问答」可即时验证

### 语音引擎
| 引擎 | 说明 |
|---|---|
| 云端微软晓晓（edge-tts） | 免费，无需 Key。依赖系统 `python3` 与 `edge_tts` 模块 |
| 本地 GPT-SoVITS | 需跑 `api_v2.py`（默认 127.0.0.1:9880），支持克隆音色、流式播放 |
| 阿里云 Qwen3-TTS | 需 DashScope Key，49 音色 |
| 百度智能云 TTS | 需 AK/SK，5 万字符/月 |

**edge-tts 需要注意**：
```bash
pip install -U edge-tts      # 旧版会被微软 GEC 校验拦截，返回 403
```
默认调用 `python3`，可用环境变量 `EDGE_TTS_PYTHON` 指向指定解释器（如虚拟环境）。

### 声音进直播间
AI 播报和弹幕朗读默认走系统扬声器，观众听不到。需在「🔊 声音设备」把输出定向到
虚拟声卡（如 Voicemeeter），再由直播伴侣把该虚拟声卡当麦克风采集。详见页内引导。

## 目录结构

```
src/
  main.js            主进程：窗口管理、CDP 点击、录制/回放、AI 决策、模型配置、TTS
  library.html       主界面（游戏库 / AI主播 / 弹幕 / 模型配置 / 声音克隆 / 声音设备）
  panel.html         自动玩控制台（含 AI 智能决策）
  ai-assist.html     AI 助手独立窗口
  voice-queue.html   语音队列窗口
  filter-rule.html   弹幕过滤规则说明
  device-guide.html  声音设备配置引导
  preload-*.js       各窗口的预加载脚本
config/              配置目录（不入版本库）
  client-config.json   AI 与模型配置（含 API Key）
  games.json           游戏库
  autoplay.json        各游戏的自动玩配置
  scripts/             录制的自动玩脚本（<游戏id>.json）
  media/ voices/       背景音乐与克隆音色
templates/           截图模板
test/tap-test.js     点击方式验证脚本（soft|cdp）
```
