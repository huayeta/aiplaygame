# AI游戏智播客户端（H5 小游戏 + 自动玩）

一个本地 Electron 客户端：游戏库 → 打开 9:16 竖屏 H5 小游戏 → 录制真人操作 → 自动回放"自动玩"。

## 运行

```bash
npm install
npm start
```

> 国内下载 Electron 二进制慢时，用镜像：
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node node_modules/electron/install.js`

## 使用流程

1. 打开后是「游戏库」，已内置「我要动个脑」。可点「+ 添加游戏」加入更多 H5 链接。
2. 点卡片「开始」，会弹出选择框：**继续上次进度** / **重新开始新游戏**，
   然后并排打开两个窗口：
   - **游戏窗口**（9:16，414×736）
   - **自动玩控制台**
3. **录制脚本**：
   - 点「● 开始录制」
   - 在游戏里正常操作（点按钮、过关）
   - 「自动标记关卡」默认开启：检测到画面切到新棋盘（变化后重新稳定、且整盘换新）会自动分关；
     也可取消勾选，改用「＋ 标记下一关」手动分关——每玩过一关、画面切到下一关时点一下
   - 自动标记的原理：不再用"画面连续变化就分关"（同一关内的点击/动画会误判），
     而是"画面变化→重新稳定→稳定画面与之前差异大（整盘换新）才分关"
   - 某一关没录好，点「↩ 撤销上一关（重新录）」可回退该关重录（可连续撤销到任意关）
   - 完成后点「■ 保存并停止」，脚本存到 `scripts/<游戏id>.json`
   - **脚本关卡管理**：列出已保存脚本的每关（含点击数），可「重录」（自动推进到该关后重新录）或「删」（删除该关）
     - 重录第 N 关：先自动回放前 N-1 关把游戏推进到第 N 关，然后进入录制覆盖该关及之后
4. **自动玩**：点「▶ 开始自动玩」，客户端按录制的点击序列自动操作；每关结束用画面相似度检测切到下一关，可循环。

## 已验证的关键结论（针对该 Unity WebGL 游戏）

- 游戏是 **Unity WebGL**，逻辑编译成 WASM，无法直接 hook 内部状态。
- **软点击（注入 JS 派发事件）无效**，游戏不响应。
- **CDP 真实点击有效**（控制台默认），但必须：
  1. 游戏窗口**可见且聚焦**（不能最小化/挪到屏幕外）；
  2. 每次点击先 `mouseMoved` 再 `mousePressed` / `mouseReleased`。
- 游戏**检测桌面端伪装手机 UA** 和**开发者工具窗口**，所以：
  - 用桌面 UA（本客户端默认，不伪装手机）；
  - 不要打开 DevTools，不要调整窗口产生大间隙，否则页面会被判定并清空。
- 进度保存在 **IndexedDB 的 `/idbfs`**（Unity IDBFS 虚拟文件系统）。
  - 点「开始」默认弹窗让你选：**重新开始新游戏**（清存档回第1关）或 **继续上次进度**。
  - 面板可设「每次打开都询问」或「总是重新开始新游戏（跳过询问）」。

## 目录结构

```
src/
  main.js            主进程：窗口、CDP 点击、录制/回放、画面相似度
  games.json         游戏库数据
  library.html       游戏库界面
  panel.html         自动玩控制台
  preload-*.js       预加载脚本
scripts/             录制的自动玩脚本（json）
templates/           截图模板
test/tap-test.js     点击方式验证脚本（soft|cdp）
```
